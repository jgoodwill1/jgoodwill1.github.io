Computational methods are central to my research. I work primarily in **Python** with high-performance numerical data generated by **VPIC and P3D** particle-in-cell simulations and spacecraft instruments.

## turbos — plasma turbulence analysis

An evolving Python analysis toolkit for multidimensional plasma data and turbulence diagnostics. The software direction includes xarray-native data loading, field/vector/tensor operations, and derived diagnostics such as pressure–strain interaction and scale filtering.

**Focus:** reusable analysis routines, transparent numerical assumptions, and easier comparison across simulation models.

*Repository and installation instructions will be linked here when the public package is ready.*

## Kinetic simulation workflows

Analysis methods for VPIC and P3D output, including density, velocity, magnetic fields, pressure tensors, velocity gradients, and spatially localized reconnection diagnostics.

**Methods:** particle-in-cell output readers, parallel data processing, periodic finite differences, low-pass Fourier filtering, Gaussian filtering, and pressure-tensor decomposition.

## Spacecraft data analysis

Parker Solar Probe and MMS analysis workflows for multiscale time series, autocorrelation estimates, interval comparisons, and boundary-aligned plasma statistics.
